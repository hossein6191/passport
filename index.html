Passport

what an AI agent actually does

An operator registers an agent and a few claims. Five validators each talk to the agent themselves, then agree — or refuse — with three words per claim.

This is not a proof of which model sits behind an endpoint; no such proof exists. It is five independent observers agreeing on behaviour, and it says inconclusive whenever the behaviour did not settle the question. Every passport, issued or refused, is on the explorer with the validators' reasons.

Inspect — the call that costs consensus

Anybody may ask. Each validator sends the public battery to the endpoint, judges each claim, and the round settles only if all of them say the same words. A refused pair (endpoint + claims) cannot be re-inspected unchanged — the operator changes something first.
